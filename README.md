## 技術メモ

- 外部依存は Google Fonts のみ（Zen Old Mincho／Zen Kaku Gothic New／Jost）
- ダークモードには追従しない（`color-scheme: light` 固定）。白ベース指定のため意図的
- トップのスクリム（暗い膜）は `.hero-scrim{z-index:1}`。`.hslide` より上に置かないと効かない
- ヘッダーはトップの上では透過＋白抜き、スクロールすると白背景に変わる（`.stuck`）
- `prefers-reduced-motion` 環境では、ズームとフェードが止まる（切替自体は続く）
- `<img>` に width/height 属性があると CSSの `aspect-ratio` より属性が優先される。
  円形にするときは `height:auto` を明示すること

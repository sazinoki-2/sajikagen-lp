# さじかげん — 栄養士の出張つくりおき

https://sazinoki-2.github.io/sajikagen-lp/

栄養士がご自宅のキッチンで、平日ぶんのおかずをまとめて作る出張サービスのページです。

## ファイル

- `index.html` … ページ本体
- `assets/img/` … 写真
- `live.py` … このPCで確認・編集するためのサーバー（編集画面つき）
- `open-editor.bat` … ダブルクリックで編集画面を開く

## このPCで編集する

`open-editor.bat` をダブルクリックすると、編集画面（ http://127.0.0.1:8210/__edit ）が開きます。
右のプレビューで文字をクリックすると左のその行に飛び、Ctrl+S で保存できます。
